# 03 - Sentencias condicionales en Java

Ejemplos cortos y progresivos para explicar en clase cómo un programa toma decisiones.

## Secuencia sugerida
1. `Ejemplo1IfSimple.java` — `if`
2. `Ejemplo2IfElse.java` — `if - else`
3. `Ejemplo3IfElseIfElse.java` — `if - else if - else`
4. `Ejemplo4CondicionesCompuestas.java` — condiciones con `&&`, `||` y `!`
5. `Ejemplo5Switch.java` — `switch`, `case`, `break`, `default`
6. `Ejemplo6PracticaGuiada.java` — práctica corta para resolver en clase

## Idea clave
La condición de un `if` debe producir `true` o `false`.
