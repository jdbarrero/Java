# 01 - Tipos de datos y variables

## Objetivo

Comprender cómo se declaran, inicializan y modifican variables en Java, reconocer los **8 tipos de datos primitivos** y diferenciar `char` de `String`.

## Ejemplos

### 1. `Ejemplo1VariablesBasicas.java`
Introduce:
- `int`
- `double`
- `char`
- `boolean`
- declaración e inicialización de variables
- cambio de valor de una variable

### 2. `Ejemplo2StringYChar.java`
Introduce:
- diferencia entre `char` y `String`
- comillas simples y dobles
- `String` como tipo por referencia
- concatenación sencilla

### 3. `Ejemplo3TiposNumericos.java`
Completa los tipos numéricos con:
- `byte`
- `short`
- `long`
- `float`
- sufijos `L` y `f`

## Tipos cubiertos

| Tipo | Ejemplo |
|---|---|
| `byte` | número de materias |
| `short` | año de ingreso |
| `int` | edad / semestre |
| `long` | población |
| `float` | temperatura |
| `double` | promedio |
| `char` | grupo / inicial |
| `boolean` | estado de matrícula |
| `String` | nombre |

## Compilar y ejecutar

Desde esta carpeta:

```bash
javac Ejemplo1VariablesBasicas.java
java Ejemplo1VariablesBasicas
```

Cambia el nombre del archivo y de la clase para ejecutar los demás ejemplos.
